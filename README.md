# Active Directory Automation Toolkit

## Overview

The Active Directory Automation Toolkit is a PowerShell-based project designed to automate common administrative tasks within a Windows Server environment.

The toolkit streamlines user provisioning, organizational unit creation, security group management, and reporting activities to reduce manual effort and improve consistency.

## Features

* Automated Organizational Unit creation
* Automated user account provisioning
* Security group creation and management
* Group membership assignment
* User and group reporting

## Technologies Used

* PowerShell
* Active Directory Domain Services
* Windows Server

## Project Structure

### Create-OUs.ps1

Creates Organizational Units for business departments.

### Create-Users.ps1

Automates user account creation and onboarding.

### Create-Groups.ps1

Creates security groups and assigns members.

### Generate-Report.ps1

Exports Active Directory users and groups into CSV reports.

## Business Value

Manual Active Directory administration can be time-consuming and prone to errors. This toolkit demonstrates how automation can improve efficiency, standardization, and scalability within enterprise environments.
